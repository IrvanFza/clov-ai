# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch. Please upgrade to the current release before reporting an issue.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use [GitHub Private Vulnerability Reporting](https://github.com/alexandephilia/clov-ai/security/advisories/new) to share a minimal reproduction, affected version, impact, and any suggested mitigation. If private reporting is unavailable, open a GitHub issue containing only the title `Security report requested`; maintainers will provide a private channel.

## What to include

- Affected CLOV version and installation method
- Operating system and runtime details
- Steps to reproduce or a minimal proof of concept
- Expected impact, including data exposure or command execution risk
- Suggested mitigation, if known

We will acknowledge reports, assess severity, and coordinate a fix before public disclosure when appropriate.
